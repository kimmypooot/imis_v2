# SALN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Employees (or HRD on their behalf) encode their SALN in IMIS, print
it on a page that reproduces the official 2025 SALN Form, AS-1 and AS-2, and
track it through HRD, the SALN Committee and the Regional Director's oath
until the signed scan is filed in the 201 File.

**Architecture:**
- **One writer.** `App\Support\HR\Saln\SalnFilings` holds the state machine
  and is the only code that changes a SALN.
- **Statements are encrypted.** The statement is an encrypted JSON array
  (`encrypted:array`). Each "generate" freezes it into an immutable
  `saln_versions` row with a reference number.
- **Printing is a standalone Inertia page**, like `PdsPrint.vue`. A backend
  paginator decides which rows land on the main form, on AS-1 and on AS-2.

**Tech Stack:** Laravel (PHP 8.4), Inertia v3 + Vue 3 (JavaScript only),
Tailwind, MySQL, and PHPUnit.

**Spec:** `docs/superpowers/specs/2026-11-25-saln-design.md`. Read it first;
this plan argues from it. The reference forms are in `docs/reference/saln/`.

## Global Constraints

- **No new Composer or npm package.** The TeX Gyre Bonum font file is the only
  asset added.
- **Encryption:** the statement and every version snapshot use
  `encrypted:array` (`APP_KEY`). Only status, type, dates and ids are plain.
- **Routes:** every route has `permission:` middleware (admin) or is
  owner-only (portal), plus a policy check through `SalnPolicy`.
- **New permissions** go in `App\Enums\PermissionName`: `saln.review` and
  `saln.manage`.
  - Both are added to `AppServiceProvider::HR_ACCESS_PERMISSIONS`.
  - `saln.manage` is seeded in `HrRoleSeeder` next to
    `EmployeeDocumentsManage`. `saln.review` is seeded to no role.
- **Self-decisions:** nobody clears or returns their own SALN, overrides
  included.
- **Spouses:** joint filing is never offered. Filing mode is "Separate
  Filing" when the spouse is in government, else "Not Applicable".
- **Who must file:** `permanent`, `temporary`, `coterminous` and
  `contractual`. Not `casual`, `job_order` or `contract_of_service`. HRD can
  exempt an employee per year, with a reason.
- **Annual:** the reckoning date is Dec 31 of year X, due Apr 30 of X+1.
- **Entry and exit:** entry is due 30 days after assumption, exit 30 days
  after separation. Only assumptions and separations on or after go-live
  (`config('hr.saln_go_live')`, default `2026-12-01`) create entry or exit
  obligations.
- **Reference format:** `SALN-{reckoning year}-{saln id, zero-padded to 5}`,
  printed with ` v{version}`. Example: `SALN-2025-00042 v2`.
- **Print page:**
  - `@page { size: 8.5in 13in; margin: 0 }`
  - margins drawn inside the page: top 0.17in, right 0.1875in, left 0.25in
  - bottom 0.125in (main form), 0.19in (AS-1 and AS-2)
  - font family `"Bookman Old Style", "TeX Gyre Bonum", serif`
- **Official blank data rows per table**, counted from the reference `.docx`
  files:

  | Table | Main form | AS-1 | AS-2 |
  |---|---|---|---|
  | children | 2 | — | — |
  | real properties | 4 | 4 | 4 |
  | personal properties | 6 | 4 | 4 |
  | liabilities | 4 | 4 | 4 |
  | business interests | 2 | 2 | 3 |
  | relatives | 4 | — | — |

- **UI:** design-system components (`resources/js/Components/`) and tokens
  only. Toasts for flash messages, icon row actions, and no coloured left
  bars. The print page stays light.
- **PHP:** run `vendor/bin/pint --dirty --format agent` before each commit.
- **Release notes:** add the work to the current month's What's New draft
  (`3.0.0-beta.N`). Don't create a new version.
- **Commits:** commit only if the user has asked for commits in this
  session. Otherwise leave the changes staged and report them. Every commit
  message ends with
  `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Editing after printing.** An employee who edits after generating and
   hands in the older paper copy: HRD may receive only the latest version.
   Receiving any other version fails with a message naming the latest
   reference. (Test in Task 3.)
2. **Children around their 18th birthday.** A child who turns 18 on or
   before the reckoning date is excluded; one who turns 18 the day after is
   included. Age is computed as of the reckoning date. (Test in Task 2.)
3. **"N/A" and blank amounts.** Assessed and market values of "N/A" are
   allowed and excluded from no total, because totals sum acquisition cost
   and balances only. A non-numeric acquisition cost is rejected. Amounts are
   summed in centavos, so `0.10 + 0.20` prints `0.30`. (Test in Task 2.)
4. **Separated employee or no account.** HRD can open, encode, generate and
   file for an employee whose account is inactive or missing, and the
   employee's own routes stay closed to anyone else. (Test in Task 6.)
5. **The Regional Director's own SALN.** Oath mode `regional_director` is
   refused when the filer is the current ORD head from `OfficeHeads`,
   including an OIC. The officer printed comes from the version snapshot,
   not from today's head. (Test in Task 3.)

### Task 2: The statement — normalising, totals, children, pre-fill

**Files:**
- Create: `app/Support/HR/Saln/SalnStatement.php`,
  `app/Support/HR/Saln/SalnPrefill.php`
- Test: `tests/Unit/HR/SalnStatementTest.php` (pure functions),

**Statement shape (pinned; every later task uses it):**
```
declarant: {family_name, first_name, middle_initial, position, agency, office_address}
spouse: null | {family_name, first_name, middle_initial, in_government: bool, position, agency, office_address}
other_spouses: [string]            // multiple marriages; [] prints "Not Applicable"
children: [{name, birth_date (Y-m-d), age}]
real_properties: [{owner, description, kind, location, assessed_value, market_value, acquisition_year, acquisition_mode, acquisition_cost}]
personal_properties: [{owner, description, acquisition_year, acquisition_cost}]
liabilities: [{owner, nature, creditor, outstanding_balance}]
no_business_interests: bool, business_interests: [{owner, name, address, nature, acquired_on}]
no_relatives: bool, relatives: [{name, relationship, position, agency_and_address}]
government_id: {type, number, issued_on}
totals: {real_properties, personal_properties, total_assets, total_liabilities, net_worth}   // strings "1234.50", server-computed
```

**Interfaces (Produces):**
- `SalnStatement::rules(): array`, the validation rules for the shape
  above:
  - `assessed_value` and `market_value` accept a decimal or `N/A`
  - acquisition cost and balance accept a decimal ≥ 0
  - `owner` uses `SalnOwner`
  - `relatives` is required unless `no_relatives`, and the same for
    business interests
- `SalnStatement::withTotals(array $statement): array` returns the
  statement with `totals` recomputed:
  - integer centavos throughout
  - real and personal subtotals sum `acquisition_cost` over all owners
  - net worth is total assets minus total liabilities, and may be negative
- `SalnStatement::filingMode(array $statement): string` returns `separate`
  or `not_applicable`.
- `SalnPrefill::for(Employee $employee, SalnType $type, CarbonImmutable $asOf): array`:
  - **Declarant:** name from the PDS personal section (middle initial from
    the middle name); position from the user's position; agency
    `Civil Service Commission Regional Office VIII`; office and address
    from the organizational unit.
  - **Spouse:** from the PDS family section, or null when there's no
    surname. `in_government` is false.
  - **Children:** PDS children with a birth date and `age < 18` as of
    `$asOf`, with `age` filled in.
  - **Everything else** is empty arrays and false flags.
- `SalnPrefill::fromPrevious(Saln $filed, SalnType $type, CarbonImmutable $asOf): array`:
  - copies the latest version's statement
  - re-runs the children filter for `$asOf`
  - drops `totals` and `government_id`

### Task 3: `SalnFilings` (the state machine) and `SalnPolicy`

**Files:**
- Create: `app/Support/HR/Saln/SalnFilings.php`, `app/Policies/SalnPolicy.php`
- Modify: `app/Providers/AppServiceProvider.php` (`Gate::policy`)
- Test: `tests/Feature/HR/SalnFilingsTest.php`

**Interfaces (Produces); every method runs in a transaction, audits, and
throws `InvalidArgumentException` with a user-facing message on a bad
transition:**
- `open(Employee $e, SalnType $type, CarbonImmutable $asOf, User $by, bool $fromPrevious = false): Saln`
  - starts a Draft
  - for Annual, `$asOf` must be Dec 31
  - throws if a SALN already exists for that (employee, type, date); the
    caller redirects to it instead
- `save(Saln $s, array $statement, SalnOathMode $mode, ?string $officerName, ?string $officerTitle, User $by): void`
  - only when `status->isEditable()`
  - validates with `SalnStatement::rules()` and stores `withTotals()`
  - `RegionalDirector` is refused when the employee's user is the current
    ORD head
  - `OtherOfficer` requires a name and title
- `generate(Saln $s, User $by): SalnVersion`
  - only when editable
  - increments `current_version` and writes the version with its reference
  - snapshots the officer: for `RegionalDirector`, the name and position of
    the ORD head from `app(OfficeHeads::class)->all()`; for `Notary`, null;
    for `OtherOfficer`, the given values
  - sets the status to Generated and records a `generated` event
- `receive(Saln $s, int $version, User $by): void`
  - only Generated, and only `$version === current_version`; otherwise
    throws "Only the latest printout, {reference} v{n}, can be received."
  - sets Received
- `decide(Saln $s, bool $clear, ?string $remarks, User $by): void`
  - only Received, never by the employee's own user
  - a return requires remarks
  - `override` is true when `$by` lacks `saln.review`
  - sets Cleared or Returned and notifies the employee with `HrUpdate`
- `file(Saln $s, UploadedFile $scan, User $by): EmployeeDocument`
  - only Cleared
  - stores through `EmployeeDocuments::store`:
    - type `EmployeeDocumentType::Saln`
    - title `"SALN — {type label} {Y or Y-m-d}"`
    - document date = reckoning date
  - sets Filed and the link to the document
- `exempt(Employee $e, int $year, string $reason, User $by): SalnExemption`
- **`SalnPolicy`:**
  - `view`: owner, `saln.manage`, or `saln.review` once status ≥ Received
  - `update` (save, generate): owner while their account is active, or
    `saln.manage`
  - `decide`: `saln.review` or `saln.manage`, and not the owner
  - `receive` and `exempt`: `saln.manage`
  - `file`: `saln.manage`, or the owner when Cleared

### Task 5: The print page and AS-1/AS-2 pagination

**Files:**
- Create: `app/Support/HR/Saln/SalnSheets.php`,
  `resources/js/Pages/HR/SalnPrint.vue`,
  `public/fonts/tex-gyre-bonum/*.woff2` (regular and bold, with the GUST

- Test: `tests/Unit/HR/SalnSheetsTest.php`

**Interfaces (Produces):**
- `SalnSheets::ROWS`, the row table from Global Constraints, keyed
  `main|as1|as2` → `children|real_properties|personal_properties|liabilities|business_interests|relatives`.
- `SalnSheets::layout(array $statement): array` returns
  `{main: {...rows per table}, as1: [{...}], as2: [{...}]}`. Each sheet's
  tables are padded with nulls to the official row count. The rules:
  - **Main form:** declarant-owned rows go here up to its counts; the
    overflow fills AS-1 sheets, as many as needed.
  - **AS-2:** spouse- and child-owned rows go here, as many sheets as
    needed. They never go on the main form.
  - **Children and relatives** never move to another sheet. When they
    exceed 2 or 4 rows, their main-form table grows (the electronic-form
    alteration the FAQ allows).
  - **Sheet totals:** each AS sheet carries its own subtotals. The main
    form's totals are the statement's `totals`, covering every owner.
- **`SalnPrint.vue` props:**
  - `version: {reference, version, statement, oath_mode, officer_name, officer_title}`
  - `saln: {type, reckoning_date}`
  - `layout` (from `SalnSheets`)
  - `pageCount`
- **What the page renders:** the main form (2 pages), each AS-1, then each
  AS-2. The layout rules:
  - **Measurements:** taken from the `.docx` files (twips ÷ 1440 = inches):
    column widths, row heights, borders, shading, font sizes (half-points ÷
    2) and the footnotes.
  - **Footer:** "Page X of Y", counting every sheet, plus the reference
    `IMIS {reference} v{n}` in 6pt, in the bottom margin, so no form content
    moves.
  - **Check boxes:** drawn boxes, ticked from the statement: compliance
    type, filing mode, not applicable, none flags.
  - **Oath block:**
    - `regional_director` or `other_officer`: the officer's name and title
      under "(Person Administering Oath)"
    - `notary`: blank
  - **Screen-only bar** (`@media print { display: none }`):
    - Print button and the reference
    - the settings line "Paper 8.5 × 13 in (Long) · Margins: None · Scale
      100% · Background graphics on"
    - a warning when `!document.fonts.check('10pt "Bookman Old Style"')`
